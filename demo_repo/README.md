# Demo Repository

Dette er et bevidst minimalt repository, der bruges til at demonstrere
AgentOps Developer Platform's coding agent. Det indeholder en lille
`calculator`-pakke med en bevidst indsat bug og en tilhørende test-suite.

Se `/scripts/run_demo.py` i hovedprojektet for den fulde, reproducerbare
demonstration af agenten, der finder og retter buggen.
